# M-Ride (Mpumalanga Launch Demo)

Release demo of M-Ride — affordable, safe rides and deliveries launching in **Mpumalanga Province** (Ehlanzeni, Nkangala, and Gert Sibande districts).

```bash
npm install
npm run dev
```

Optional: copy `.env.example` to `.env.local` and set `VITE_GOOGLE_MAPS_API_KEY`.

See `/cursor/stores/self/docs/m-ride-demo-notes.md` for full demo notes (in the Project store).
